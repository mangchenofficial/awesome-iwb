# 🧩 ClassIsland 插件

ClassIsland 的扩展插件生态，为课表软件增添更多实用功能。所有插件均需要在 ClassIsland 本体软件中加载使用。

> ℹ️ 如需安装插件，请在 ClassIsland 中打开「应用设置」→「插件」→「加载插件」，选择下载的插件文件即可。

### 热门社区插件推荐

以下是一些社区热门的第三方插件：

| 插件名 | 简介 | 开发者 |
|--------|------|--------|
| **天气预警** | 在 ClassIsland 中显示天气预警信息 | 社区 |
| **自定义壁纸** | 为 ClassIsland 添加自定义壁纸功能 | 社区 |
| **课表导出** | 导出课表数据为图片或文件 | 社区 |
| **语音播报** | 上下课时语音播报课程信息 | 社区 |
| **今日值日** | 显示今日值日生信息 | 社区 |

更多插件请访问 [ClassIsland 社区插件索引](https://github.com/ClassIsland/PluginIndex)。
